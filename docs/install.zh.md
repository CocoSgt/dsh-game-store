# 安装游戏商店

游戏商店是 DeepSeek Harness（DSH）的一个插件。先装好 DSH，再装商店。

## 在桌面版里安装

1. 打开 DSH，点侧栏的“插件”。
2. 点“安装插件”，输入 `dsh-game-store`，确认。
3. 按提示重启 DSH。
4. 侧栏底部出现“游戏商店”，点开。

## 用命令行安装

```bash
dsh plugin --profile web add dsh-game-store
```

`web` 换成你平时用的 profile 名字。装完重新启动这个 profile。

## 安装和玩游戏

1. 在商店里点一个游戏，看说明和截图。
2. 点“安装”。商店会下载目录里登记的那个版本，并核对校验值。
3. 点“开始游戏”。游戏占满整个窗口并进入全屏。
4. 鼠标移到窗口顶边，会出现一个小条：重新开始、全屏、退出游戏。

装好的游戏在“我的游戏”里。游戏有新版本时，按钮会变成“更新到 x.y.z”。

## 存档在哪里

存档在你的电脑上，由 DSH 的浏览器内核保管。更新游戏、卸载后重装，存档都还在。

## 游戏安全吗

商店只安装目录里登记过的版本，上架前查过恶意代码。游戏在自己的本地地址里运行，读不到 DSH 的数据和你的文件。大多数游戏不联网；会联网的游戏，游戏页上写明了它连哪些服务器，要不要装由你判断。商店做到的和做不到的，都写在[规范的“安全”一节](../SPEC.md#9-安全)。

## 卸载

- 卸载一个游戏：打开游戏页，点“卸载”。存档保留。
- 卸载商店：在 DSH 的插件页里移除 `dsh-game-store`。已装的游戏要在插件页里各自移除。
